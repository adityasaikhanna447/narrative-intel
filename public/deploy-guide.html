Step-by-Step Setup
1
Get Your API Keys
You need 3 keys. Get them all before starting deployment.

Gemini (required): Go to aistudio.google.com/app/apikey → Create API Key → Copy it.

Resend (required): Go to resend.com/signup → Create account → API Keys → Create API Key → Copy it. Also go to Domains → Add your email domain OR use their test domain for now.

Serper (optional but recommended): Go to serper.dev/signup → Get API key → 2,500 free queries.
~5 minutesAll Free
2
Upload Project to GitHub
Go to github.com/new → Create a new repository named narrativeintel → Set it to Public (required for free GitHub Actions).

Then upload the project files. The easiest way — no terminal needed:
GitHub repo → click uploading an existing file → drag and drop the entire narrativeintel folder contents → Commit changes.
~5 minutesFree
3
Deploy to Vercel
Go to vercel.com/new → Sign in with GitHub → Import your narrativeintel repository → Click Deploy.

Vercel will automatically detect the project structure and deploy it. Your app gets a URL like narrativeintel.vercel.app.

After deploy, go to your project → Settings → Environment Variables → Add all variables from the table below.

4
Add Secrets to GitHub Actions
Go to your GitHub repo → Settings → Secrets and variables → Actions → New repository secret.

Add these two secrets:

VERCEL_WATCHER_URLhttps://your-project.vercel.app/api/watcher (your Vercel URL + /api/watcher)

~3 minutesFree
5
Test It Manually First
Before waiting 30 minutes, test the watcher manually.

Go to your GitHub repo → Actions tab → NarrativeIntel — News Watcher → Run workflow → Run workflow.

Watch the logs. You should see stories being fetched, scored, and if any hit the threshold, an email sent. Check your inbox — first alert should arrive within 2 minutes. 
Expected log output:
[India Breaking] fetched 15 stories
[India-Pakistan] HIGH SCORE: 84 — India Suspends Water Treaty...
EMAIL SENT: India Suspends Water Treaty After Attack
alerts_sent: 1
~2 minutes
6
Set Up Resend Domain (for real email delivery)
By default, Resend can only send to your own verified email on the free tier. To send properly:

Option A (easiest): Use onboarding@resend.dev as the from address — works immediately, no domain needed.

In api/watcher.js, change the from line to: 
from: 'NarrativeIntel <onboarding@resend.dev>',
Option B: Add your own domain in Resend → Domains → Add Domain → follow DNS setup instructions. Takes 5 minutes, gives you alerts@yourdomain.com.

Tuning the System
Getting too many emails? Raise MIN_SCORE to 75 or 80 in Vercel env vars.
Missing stories? Lower MIN_SCORE to 60. Add more topics to WATCH_TOPICS in api/watcher.js.
Wrong topics? Edit the WATCH_TOPICS array in api/watcher.js — each has a query and threshold.
Want faster alerts? Change the cron schedule in .github/workflows/watcher.yml from */30 * * * * to */15 * * * * for every 15 minutes.
Honest Limitations
Speed: You get alerts within 15–30 minutes of a story appearing in Google News RSS — not the second it breaks on Twitter. For the absolute latest breaking news (like live attacks or live verdicts), you'll still see it on Twitter/WhatsApp first. This system is for considered stories that have appeared in news sources — which is actually the right level for video content, since you need verified facts, not live rumours.

Deduplication: The current version uses in-memory deduplication which resets when the Vercel function cold-starts. This means you might occasionally get the same story twice. A future version can add Vercel KV storage for persistent dedup — free on Vercel too.
